# Benchmark Taxonomy for Genome Foundation Models

This page organizes common benchmark categories for DNA and genome modeling research.

## 1. Sequence-level benchmarks

- Regulatory element prediction
- Variant effect prediction
- Splice-site classification

## 2. Multi-omics benchmarks

- Gene expression prediction
- Single-cell representation reviews
- Cross-species transfer evaluation

## 3. Long-context evaluation

- Long-range dependency accuracy
- Context window sensitivity
- Genome-scale sequence reasoning

## 4. Practical deployment benchmarks

- Inference efficiency
- Memory footprint
- Data availability and reproducibility
