# Genome Foundation Models: Latest Papers & Links

A curated list of recent DNA/genome foundation model papers, along with official links and code resources. This repository is intended as a lightweight reading list for researchers and engineers tracking progress in genomic modeling.

## Why this matters

Genomic foundation models are moving from short sequence encoders to long-context, multi-omics, and generative systems. They are increasingly used for regulatory prediction, variant interpretation, gene expression modeling, and sequence design.
