# Genome Foundation Model Index

This page groups the most relevant genomic foundation models into a practical reading path.

## Core genomic backbone models

- Nucleotide Transformer — human genomics foundation model, long-range sequence learning
- DNABERT-2 — multi-species genomic modeling with improved tokenization
- HyenaDNA — long-context single-nucleotide DNA modeling
- Geneformer — single-cell gene expression representation learning
- Caduceus — long-range equivariant DNA modeling

## Recent 2024-2025 frontier models

- JanusDNA — bidirectional hybrid DNA foundation model
- SPACE — genomic profile predictor, DNA foundation model
- GENERator — long-context generative genomic foundation model
- dnaGrinder — lightweight high-capacity genomic foundation model
- GenBench — benchmark suite for genomic foundation model evaluation
- Metro — benchmark for DNA foundation model evaluation

## Recommended reading sequence

1. Nucleotide Transformer
2. DNABERT-2
3. HyenaDNA
4. Geneformer
5. Caduceus
6. JanusDNA / SPACE / GENERator
7. GenBench / Metro for evaluation and benchmarking
